# Face Production

A responsive recreation of the supplied Face Production casting-agency references.

## Run locally

```bash
npm install
npm run dev
```

Open the local address printed by the development server.

## Build

```bash
npm run build
```

## Notes

- The header, typography, buttons, process steps, icons, dividers, menu, and responsive behavior are implemented as real interface elements.
- The casting-board imagery is preserved as a dedicated decorative asset rather than flattening the whole page into a screenshot.
- The mobile composition switches to a stacked layout with both actions above the casting board and horizontal process rows below it.
